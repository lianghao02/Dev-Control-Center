# 長耗時任務互動與取消規範 (Long-Running Tasks)

## 1. 耗時任務處理原則
- 若操作會造成使用者可感知之等待或 UI 無回應風險（如巨量檔案轉檔、視訊片段切分、大量 PDF 抽取）：
  - 應避免於主執行緒執行，建議派發至工作緒（`Task.Run`, `QThread`, `Worker` 等）。
  - 主畫面控制項應適當防連點，並維持視窗可拖曳、最小化與即時響應。
  - 具體門檻依專案實測與體感決定，不以固定秒數作為強制邊界。

## 2. 互動四要素
1. **即時進度條 (Progress Bar)**：數值型（0% ~ 100%）或無法預估時之跑馬燈（Indeterminate）。
2. **進度文字提示**：清晰標註目前進度，如「正在處理第 42 / 150 筆：IMG_0042.jpg」。
3. **取消按鈕 (Cancel Button)**：支援即時中止，在下一個檔案迭代週期安全停止，並清理暫存檔。
4. **結果摘要彈窗/通知**：作業完成或中斷時，呈現明確統計結果（成功、失敗、跳過）。
