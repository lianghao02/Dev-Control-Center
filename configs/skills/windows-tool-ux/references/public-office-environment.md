# 公務行政電腦環境特徵 (Public Office Environment)

## 1. 現場設備與網路特徵
- **硬體受限**：常見 4~8GB 記憶體之老舊 PC、機械式傳統硬碟 (HDD) 或老舊 i3/i5 處理器。
- **網路隔離**：多數辦公電腦處於內部封閉實體隔離網路，無法連外、無法調用外部 CDN、無法下載 Python pip 或 npm 套件。
- **資安軟體控管**：嚴格的端點防毒（EDR、防毒軟體）會即時攔截可疑的批次 PowerShell 提權、未知腳本下載或跨目錄暫存注入。

## 2. 產品對策
- 預設採本機離線優先設計，字型、圖示與必要函式庫建議內建或採本機可用資源。
- 免安裝 Exe 避免設計依賴未經授權之外部動態下載。
- 未經使用者或正式業務規格明確授權，避免使用需要強行聯網授權或外部註冊登入之設計。
