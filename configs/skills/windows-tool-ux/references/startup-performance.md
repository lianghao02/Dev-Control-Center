# 啟動效能與防假死策略 (Startup Performance)

## 1. 啟動回應原則 (Startup Responsiveness)
- 使用者啟動程式後，首頁主視窗應盡快呈現並處於可互動狀態，避免無回應等待。
- **注意事項**：
  - 避免在視窗彈出前進行重量級網路連線、完整磁碟掃描或長時間同步比對。
  - 主執行緒（UI Thread）應避免執行長時間 Blocking I/O，若有耗時初始化應考慮非同步或延遲載入。

## 2. 漸進式載入模式
- **延遲初始化 (Lazy Initialization)**：大型字典、AI 模型權重、圖庫快取僅在使用者點擊進入對應功能標籤頁時才進行載入。
- **背景工作緒 (Background Worker)**：非必要檢查（如版本更新偵測、硬碟剩餘空間檢查）一律置於背景 Task/Thread，完成後以非同步方式更新 UI 角標。
