# Windows 10/11 相容性檢核清單 (Windows Compatibility Checklist)

- [ ] 1. 在 Windows 10 (21H2+) 與 Windows 11 均可正常啟動與操作。
- [ ] 2. 測試路徑含中文（如 `測試中文資料夾`）與空白時，所有功能運作正常。
- [ ] 3. 在非本機 Administrator 一般使用者權限下，無發生 UAC 強制提權或存取拒絕。
- [ ] 4. 外部子行程呼叫均使用 UTF-8 編碼與引號安全包裹路徑。
- [ ] 5. 版本專屬 API／視覺效果已偵測並驗證相容替代方案（無此功能可列不適用及理由）。

## 雙系統實機證據

對適用的 Windows 桌面工具，在相同發布包與測試資料下分別填寫；每格附結果與證據位置，失敗附重現步驟。未執行一律填「待本機驗證」，不得以另一系統、編譯或瀏覽器模擬結果代填。

| 項目 | Windows 10（21H2+，記錄實際組建） | Windows 11（記錄實際組建） |
|---|---|---|
| 實機冷啟動、核心任務與錯誤復原 | 待本機驗證 | 待本機驗證 |
| 繁中文字型、長文字／訊息無缺字裁切 | 待本機驗證 | 待本機驗證 |
| 100%／125%／150% DPI、視窗縮放及最大化／還原；支援多螢幕時跨 DPI 移動 | 待本機驗證 | 待本機驗證 |
| 含中文與空白路徑、一般使用者讀寫權限 | 待本機驗證 | 待本機驗證 |
| 免安裝包在乾淨環境啟動（依 portable-release.md） | 待本機驗證 | 待本機驗證 |
| 離線、低資源環境與版本專屬功能替代（依實際架構） | 待本機驗證 | 待本機驗證 |

一併記錄包版本／雜湊、硬體、執行階段與 DPI；保留修改前後同條件畫面及操作結果。設定調整須經使用者允許，測完還原；不為驗收自動更改使用者系統設定。
