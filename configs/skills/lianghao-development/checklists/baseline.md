# 任務起始基準檢核清單 (Baseline Checklist)

在開始任何任務前，必須確認以下事項：
- [ ] 1. 執行 `git status` 確認當前分支與工作目錄狀態。
- [ ] 2. 確認無未預期的未提交變更。
- [ ] 3. 讀取專案之 `AGENTS.md` 與最新 `HANDOFF.md`。
- [ ] 4. 確認任務型態（AUDIT / EVALUATE / FIX / IMPROVE / RELEASE / HANDOFF）。
- [ ] 5. 若為 AUDIT 任務，嚴格遵守唯讀限制，不變更任何檔案。
- [ ] 6. 若涉及不可逆操作，確認備份或模擬預覽機制已就緒。
