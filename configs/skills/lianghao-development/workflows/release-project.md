# RELEASE 專案發布流程 (Release Workflow)

## 發布檢核道門 (Release Gates)
1. **Git 潔淨與同步檢核**：
   - Working Tree 為 Clean 狀態。
   - 分支已與遠端對齊，無衝突或遺漏提交。
2. **完整測試與建置驗收**：
   - 執行全套自動化測試，通過率 100%。
   - 若為桌面應用，執行建置並驗證免安裝發行套件可正常啟動。
3. **版本號與文檔更新**：
   - 更新 `version.txt`（若存在）。
   - 更新 `CHANGELOG.md`，填寫繁體中文發布說明與亮點。
4. **機敏資訊與路徑檢驗**：
   - 確認發布檔案未包含任何敏感資訊或本機個人絕對路徑。
5. **產出發布報告**：
   - 依 `templates/release-report.md` 產出發布總結。
