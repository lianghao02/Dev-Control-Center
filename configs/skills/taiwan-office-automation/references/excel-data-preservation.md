# Excel 資料語意與完整性保護 (Excel Data Preservation)

## 1. 受保護欄位類型
下列欄位在讀取、轉換、寫入 Excel（.xlsx, .xls, .csv）時，**預設必須以純文字 (String / Text) 型別保存**，嚴禁自動轉為數值：
- **金融帳號**：銀行代碼（3 碼）、分行代碼、銀行帳號（10~16 碼）。
- **身分識別碼**：國民身分證統一編號、居留證號、護照號碼。
- **通訊號碼**：市話（含區碼如 `02`、`04`）、行動電話（`09` 開頭）、國際碼。
- **長數字與編號**：案件編號、公文文號、統一發票字軌號碼、ATM 機台代號、IMEI 碼、SIM 卡卡號。
- **具前導零代碼**：郵遞區號（3+2 或 3+3 碼）、單位代碼、班次序號。

## 2. 嚴防科學記號破壞
- 超過 11 位之純數字欄位，在 Excel 預設常會被轉換為科學記號（例如 `123456789012345` 變為 `1.23457E+14`），造成後續低位精度永久丟失。
- **防禦手段**：
  - 若輸出明確只供可信 Excel 工作流雙擊開啟，可作為相容性選項將字串包裹為 `="123456789012345"`；標準資料交換 CSV 應保存原值，避免變更原始語意或引入公式注入 (Formula Injection) 疑慮，並由匯入端或原生 XLSX/工作表寫入端控制欄位型別。
  - 在 OpenXML / ClosedXML / EPPlus / openpyxl 輸出時，儲存格資料型別必須明確指定為 `Text`（`cell.SetCellValue(value.ToString())` 並設定格式為 `@`）。

## 3. 金額與識別碼嚴格分離
- **金額欄位**：可被解析為數值（Decimal / Int64），可執行加總、千分位格式化（`#,##0`）或負數標註。
- **識別碼欄位**：絕對不可參與任何數學運算，也不可套用千分位或去零處理。
