# 安全批次處理作業流程 (Safe Batch Process Workflow)

1. **依序迭代檔案**：依字母或時間排序走訪檔案，維持可重現性。
2. **處理前衝突檢查**：對每個輸出目標檢查是否存在同名檔案，套用指定之衝突處理策略（如 Version Suffix）。
3. **複製與驗證**：
   - 複製檔案至目標路徑。
   - 驗證目標檔案大小是否與來源一致。
4. **即時進度反饋**：長耗時作業每秒或每百分之一更新進度條與目前處理檔名。
5. **產出最終驗收摘要**：
   - 報告欄位包含：輸入筆數 (Input count)、已處理 (Processed)、已複製 (Copied)、已搬移 (Moved)、跳過 (Skipped)、重複 (Duplicate)、失敗 (Failed)、輸出筆數 (Output count)。
