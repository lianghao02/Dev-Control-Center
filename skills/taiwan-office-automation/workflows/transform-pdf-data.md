# PDF 資料擷取與轉換作業流程 (Transform PDF Data Workflow)

1. **PDF 類型檢測**：
   - 快速讀取首頁文字串流，若文字長度大於閾值則判定為「文字型 PDF」。
   - 若為空字串或僅含點陣圖物件，則標記為「掃描型 PDF」。
2. **文字型 PDF 擷取**：
   - 使用純文字剖析器擷取表格與段落文字。
   - 保留表格欄位座標與對齊關係。
3. **掃描型 PDF 處理**：
   - 將頁面渲染為 300 DPI 影像後，調用本機離線 OCR 引擎進行辨識。
4. **結構化匯出**：
   - 將辨識結果結構化為 JSON 或表格格式，並輸出至指定目錄。
