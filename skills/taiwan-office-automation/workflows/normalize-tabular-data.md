# 表格資料型別偵測與正規化作業流程 (Normalize Tabular Data Workflow)

1. **編碼偵測與載入**：優先嘗試 UTF-8（無 BOM / 帶 BOM），若失敗或亂碼則退回 Big5 / CP950，取得純文字表格資料。
2. **欄位屬性判定**：
   - 識別欄位是否為「帳號、電話、身分證號、代碼」➜ 標記為 `String/Text`，保留原始所有字元與前導零。
   - 識別欄位是否為「民國/西元日期時間」➜ 依規則轉換為標準 ISO 日期時間。
   - 識別欄位是否為「金額/數量」➜ 清理非數字字元（如貨幣符號、逗號）後轉為數值型別。
3. **資料驗證與異常輸出**：
   - 對不合法之帳號格式或日期標示警告。
   - 統計處理總筆數、成功正規化筆數與異常筆數。
