# 桌面工具 UI/UX 審核與流暢度診斷流程 (Review Desktop UX Workflow)

1. **首屏可見度與冷啟動檢查**：
   - 觀察程式啟動流暢度，確認主視窗盡速呈現且無可感知之凍結假死。
   - 檢查視窗彈出前是否有不必要的 Blocking 工作。
2. **高 DPI 與文字縮放檢視**：
   - 將 Windows 顯示設定調整為 125% 與 150%，逐頁檢查是否有按鈕文字被截斷、標籤重疊。
3. **空狀態與錯誤提示檢查**：
   - 檢視無資料時是否有清楚引導（如「請將檔案拖曳至此」），非留下一片空白。
   - 模擬錯誤情境，確認錯誤視窗能說明原因並給出下一步指引。
