# 安全檔案整理與分類流程 (Safe Organize Workflow)

1. **依中繼資料解析分組**：
   - 提取照片 EXIF 拍攝年份/月份（`YYYY/MM`）或文件日期。
   - 若檔案無中繼資料，回退至檔案最後修改時間，或標記至未確定日期目錄（如 `Unknown_Date/` 或 `No_Date/` 示例）。
2. **建立目錄架構**：依年份/月份動態建立目標分類目錄。
3. **複製歸檔與記錄**：
   - 將檔案安全複製至對應年份目錄。
   - 記錄歸檔對照表（`mapping.json`）。
4. **來源比對驗收**：
   - 確認目標目錄中的檔案總數與來源匹配，雜湊校驗無誤。
