# 異常隔離與安全復原設計 (Rollback and Quarantine)

## 1. 隔離區機制 (Quarantine Policy)
- 當批次處理遇到：
  - 格式損毀無法解析之照片/影片。
  - 含有危險指令碼/巨集之 Office 文件。
  - 檔名異常長或含有作業系統禁止字元之檔案。
  - 雜湊比對衝突但無法判定何者較新之疑義檔案。
- **處置原則**：建立隔離或待審目錄（名稱依專案風格自訂，如 `Quarantine/`、`Review/`、`_unresolved/` 等），保留完整原始檔名與副檔名，並產生清單日誌記錄原因。**嚴禁未經確認直接將疑義檔案丟棄**。

## 2. 交易式日誌與復原 (Audit Log & Rollback)
- 大規模搬移或改名時，應記錄原子操作交易日誌（JSON 或 CSV）：
  ```json
  { "timestamp": "2026-09-14T10:00:00", "action": "move", "from": "C:/src/a.jpg", "to": "D:/dst/2026/09/a.jpg" }
  ```
- 發生中途崩潰或中斷時，系統可依日誌進行一鍵復原（Rollback），將已搬移檔案原路退回。
