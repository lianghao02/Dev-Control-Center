# 原始輸入資產唯讀防護原則 (Source Data Protection)

## 1. 核心不可侵犯原則
- **來源目錄唯讀對待**：
  - 應用程式處理使用者指定的原始目錄時，所有檔案控制代碼（File Handle）預設以 `ReadOnly` 模式開啟。
  - 嚴禁直接在來源目錄進行原地更名（In-place rename）、原地覆寫或原地解壓縮。
- **輸出隔離**：
  - 處理完成之檔案一律寫入至使用者指定的「目標目錄」或預設之 `_processed/` / `_organized/` 子目錄。

## 2. 例外操作條件
僅在滿足下列全部條件時，才允許對來源目錄進行寫入或清理：
1. 產品規格核心功能即為就地整理（例如使用者明確點選「整理後刪除來源」）。
2. 作業前已有清晰之 UI 警示與二次彈窗確認。
3. 目標檔案已經過完整寫入且大小/雜湊驗證通過。
