# 目標檔案同名衝突處置規範 (Collision Handling)

## 1. 嚴格禁止行為
- **嚴禁無提示直接覆寫**：在批次相片整理、影音轉檔或報表生成時，若目標路徑已存在同名檔案，絕對不可直接覆寫。

## 2. 五大標準衝突策略
應用程式應提供下列明確策略供設定或預設套用：
1. **Skip（跳過）**：保留目標檔案，略過來源檔案，並於記錄檔中記載「衝突跳過」。
2. **Version Suffix（自動序號後綴，建議預設）**：
   - 保留兩者，自動對新檔案命名為 `IMG_0001 (1).jpg`、`report_v2.xlsx`。
3. **Compare Hash（內容比對）**：
   - 若檔案大小與 SHA-256 雜湊完全相同，判定為同一檔案安全跳過。
   - 若內容不同，自動升級為 Version Suffix 或 Quarantine。
4. **Quarantine / Review（隔離或待審區）**：
   - 將衝突檔案保留並移至隔離或待審目錄（如 `_collisions/`、`_review/` 等，名稱依專案定義）供後續核對。
5. **Prompt / Confirm（個別確認）**：
   - 在 GUI 介面跳出對話框供使用者選擇「覆寫、保留兩者、略過」。
