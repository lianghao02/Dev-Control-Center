# AUDIT 專案唯讀健康檢查流程 (Audit Workflow)

## 任務邊界限制
> ⚠️ **鐵律：AUDIT 任務為 100% 唯讀檢視，絕對不得修改任何程式碼、文件或設定檔案。**

## 執行步驟
1. **確認 Git 狀態**：
   - 檢視分支、上游狀態、未提交變更與未追蹤檔案。
   - 記錄當前 Commit SHA 與遠端同步狀況。
2. **檢視架構與治理文件**：
   - 檢查 `AGENTS.md`、`README.md`、`CHANGELOG.md` 是否完整且與現況一致。
   - 檢查是否存在未記錄的重大技術債或冗餘檔案。
3. **執行唯讀測試**：
   - 執行專案現有單元測試或語法檢查（以不變更檔案為原則）。
4. **機敏與安全檢核**：
   - 檢查是否包含硬編碼路徑、密鑰、敏感資料。
5. **產出 AUDIT 報告**：
   - 列出確認事實、潛在風險、P1/P2/P3 改善建議。
