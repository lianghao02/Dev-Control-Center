# 資料安全與不可逆操作防護 (Data Safety)

## 1. 敏感機敏資料隔離
- API Key、Token、密碼、憑證、個人路徑嚴禁寫入原始碼或提交至 Git。
- 本機設定檔（如 `%USERPROFILE%\.lianghao\config.json`）必須留在本機，不入版本庫。

## 2. 100% 離線隱私防線
- 涉及執法、隱私調查、個資處理之工具，所有影音、OCR、AI 推論一律本機離線執行。
- 嚴禁未經授權引入任何外部雲端 API 或外部遙測請求。

## 3. 高風險操作防禦
- 涉及批次刪除、覆寫、搬移或不可逆操作時，優先提供預覽/模擬模式或確認機制。
- 嚴禁覆寫未提交程式碼，未經確認絕不覆寫使用者原始多媒體檔案。
