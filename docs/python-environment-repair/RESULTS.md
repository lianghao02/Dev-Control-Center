## 修復內容

1. **10 啟動阻斷**：改用完整 Python 3.13 建立 `.venv`，解決 embedded 缺 Tcl/Tk。原 `python_embed` 保留，並不宣稱舊 runtime 已補齊 Tk。
2. **10 Git runtime**：預覽後將 1,011 個檔案自索引解除追蹤，逐檔驗證存在且 SHA-256 不變。不是刪除本機檔案，也沒有重寫歷史。
3. **12／15 全域依賴與入口混用**：建立專屬環境。檢查模式唯讀；版本不符時安全停止，不偷偷使用全域 Python；正常環境不反覆安裝。
4. **embedded 使用者套件外溢**：來源入口、測試與新建置／更新重啟明確帶 `-s`。未為隔離改寫既有 `._pth`。07 正常啟動也不再每次覆寫 `._pth`。
5. **啟動器安全**：10／12／15 的 `-Force` 僅套用鎖定依賴，不刪除環境。01 已存在 runtime 時拒絕破壞性 Force；01／07 損壞環境保留現場。應用程式參數中的中文、空白與旗標可完整轉交。
6. **治理來源**：四個共用 Skill 移至 `configs/skills`，修正解析器、設定範例、同步與驗證腳本及各專案引用。新增 Python 環境操作規範與 Portable 驗證邊界。
7. **部署**：先檢查、備份，再同步憲法與 Skills 到 Codex／Antigravity。新增 `-SkipMcpConfig` 排除無關 MCP 設定，選擇性同步保留其他受管雜湊。本機 Agent 設定改為新來源，保留其他欄位，未設定環境變數。
8. **中央路由**：六個 Python 專案分開檢查；14 只驗證。建置優先專案 `.venv`／embedded，不使用浮動全域入口；07 發布路徑取自 `version.txt`。
9. **舊路徑與重現**：移除已不存在的 Python 3.11／退役專案 DLL 候選與固定磁碟快取；PDF 輔助工具改為明確指定輸入、輸出。

## 尚未驗證與保留事項

- **尚待驗證**：Win10／另一使用者／無全域 Python 電腦上的新發布包、完整原生滑鼠操作、PyInstaller 重建成品及正式更新切換。桌面畫面擷取的應用程式授權逾時，不宣稱已完成畫面操作。
- **已確認保留**：01／07 既有 `dist` 及全域大型套件未清理；舊發布包沒有被本輪來源修正自動更新，其既有入口的使用者套件載入風險仍需在下一次受控發布套用修正。
- **已確認保留**：全域及 01 仍有多種 OpenCV distribution 共用 cv2。此輪未解除安裝，避免刪除共用檔案破壞功能；後續先在候選環境驗證依賴與演算法，再評估去重。
- **範圍限定**：本輪未發現現行專案需要不存在的本機 3.11。05 CI 的 3.11 宣告不代表本機 3.11 相依，也未變更。
- **推測限制**：其他標準庫輔助腳本可能可跨版本執行，但未以語法檢查取代雙版本完整功能驗證。

依 venv-details.json 實測，10／12／15 及 PDF 工具的新環境合計約 **1.22 GiB**；14 原環境約 704.8 MiB，未重建。重複容量是本輪隔離的成本，尚未藉此刪除全域依賴。VBS 已以原生 WScript 執行器測試 Unicode 編碼與中文空白路徑。

## 保留的 Python 架構

採用最小風險方案：完整 3.13 作為目前主要開發與打包來源；3.14 保留供另行驗證的新專案，不更改命令預設或 PATH。各專案依目前可運作版本隔離，01／07 embedded 3.13.0、MarkItDown 3.12 各自維持。不因版本統一升級 AI、OCR、Qt 或影音 ABI。10 的 pyproject 與 01 的 runtime 驗證限制 <3.14，既有 PyInstaller 6.11.1 metadata 亦限制 <3.14；這些實際約束及未完成的迴歸，才是不全案升級的依據，並非宣稱 3.14 無法安裝 Torch 或 PySide6。

## 日常操作與回復

- 專案健檢：`pwsh -NoProfile -File setup_and_run.ps1 -CheckOnly`。
- 六專案健檢：控制中心 `setup_all_envs.ps1 -CheckOnly`。
- 安裝／重建只使用專案 setup 或已確認直譯器的 `-m pip`。`.venv` 不搬移；新路徑於最終位置重新建立。
- 修復前原始碼可由各專案基準 Commit 逐檔比對。回復只處理本輪檔案，不使用 `reset --hard`、`git clean` 或覆寫 07 原有修改。
- 若只要回復 10 的解除追蹤，可限定 `git restore --staged -- python_embed`；本機 runtime 從未刪除。這會重新追蹤依賴，僅作回復方式，不是建議維持狀態。
- Agent 部署前版本保留於使用者 `.codex/bridge-backups`。回復來源後應先 CheckOnly，再由同步工具備份並套用；不要將部署副本反向覆蓋正式來源。
- 大型套件與發布包清理是後續獨立工作，本輪只完成評估，不執行刪除。
